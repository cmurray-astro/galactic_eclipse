# SMC Cepheids in Three Dimensions

Interactive 3D viewer of SMC classical Cepheid positions and NIR Wesenheit
PL distances, split by the four period–age bins of
*The SMC is heating up and spreading out with age* (Murray et al.).

Live: https://cmurray-astro.github.io/galactic_eclipse/

Drag to rotate, scroll or pinch to zoom, use the legend to toggle or
solo an age bin, and set each bin's opacity and point size with its sliders. Rendered on a plain 2D canvas (no WebGL) for maximum
compatibility.
